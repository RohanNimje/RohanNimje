Signature work

01 — ScanZy Rewards

Turning offline retail loyalty into a lightweight digital experience

Role: Product Strategy · Full-Stack Engineering · Systems ArchitectureTimeline: Jan 2026 – Present · Amravati, India

ScanZy Rewards is the clearest example of how I combine product, engineering, and architecture in one problem.

Instead of relying on complex hardware setups, the product uses printable QR-based workflows to enable digital loyalty and 3D reward interactions for local retail users.

What I built

Led 0→1 product execution, from user requirements through production deployment.

Designed a cloud database architecture using MongoDB + Supabase.

Reduced cross-platform data synchronization latency by 35%.

Built autonomous background workflows using n8n + REST API integrations.

Eliminated 100% of manual merchant data processing.

Shipped production-ready interactive web experiences in under two weeks.

The lesson: good product engineering is not only about adding technology—it is about removing unnecessary complexity.

02 — Cosmolyze

AI-assisted skin analysis designed to reduce product-choice paralysis

Role: AI Engineering · Full-Stack Development · ArchitectureTimeline: Jul 2026 – Aug 2026

Cosmolyze explores how computer vision can turn a difficult consumer decision into a faster, personalized experience.

The system analyzes facial input, identifies relevant skin needs, and maps those needs to target active ingredients such as Niacinamide, Salicylic Acid, and Vitamin C.

Engineering highlights

Built a camera-based facial evaluation workflow.

Developed a modular full-stack application using Python + React.

Integrated computer-vision inference with real-time decision logic.

Optimized processing and API handling to achieve <2-second response latency.

Designed the experience around instant assessment and simplified onboarding.

Recognition

Shortlisted among top national entries from 1,000+ teams at the Idea2Impact National Hackathon.

03 — Trinity X

AI automation for physical-infrastructure fraud detection

Role: AI Engineering · Rapid Prototyping

Trinity X is an AI automation engine designed to process live verification data and identify potential physical infrastructure fraud.

Built withPython · OpenAI APIs · Live Data Processing

The prototype was designed and pitched during a 48-hour national hackathon sprint, where it received top recognition for its fraud-detection concept.

04 — Smart Hackathon Finder Bot

Replacing repetitive discovery with automation

Role: RPA · Workflow Automation

A practical automation project focused on eliminating repetitive multi-source event discovery.

Using Automation Anywhere A360, the workflow automates data collection and reduces manual search time from approximately 30 minutes to under 60 seconds.

The underlying idea is simple:

If a task is repetitive, structured, and rules-driven, it probably should not remain manual.

05 — AI Agent Development with MCP

Connecting models to real-world systems

An independent exploration into production-ready AI workflows using:

LLMs · Model Context Protocol (MCP) · Cursor IDE · External APIs

The goal is not merely to call an AI model, but to connect model-driven reasoning with live external systems and usable workflows.
